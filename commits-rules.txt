Правила оформления коммитов по Conventional Commits

Формат: type(scope): description

type — тип изменения.
scope — необязательная область изменения.
description — краткое описание.

Основные типы:

feat — добавление новой функциональности.
fix — исправление ошибки.
docs — изменение документации.
style — изменение форматирования.
refactor — изменение структуры кода без изменения поведения.
test — добавление или изменение тестов.
build — изменения сборки или зависимостей.
ci — изменения настроек CI.
chore — прочие технические изменения.

Примеры:

docs: add git commands
docs: add commit rules
feat: add user registration
fix: correct input validation

Правила:

1. Указывать тип изменения в начале.
2. После типа ставить двоеточие и пробел.
3. Писать краткое и понятное описание.
4. Не ставить точку в конце краткого описания.
5. Область изменения можно указывать в скобках: feat(auth): add login.
